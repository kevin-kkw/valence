# VALENCE · 链式反应（短闭环原型）

两波各60秒，第二波需击败失控反应釜Boss（未击败会继续战斗）：普通枪战斗收集水/氢气/氧气物质卡，钻石用于角色能力三选一；波间可直接制作或拖拽投料，按公开配方改装水枪或氢燃烧枪，进入第二波并结算。WASD/方向键移动，自动攻击，ESC暂停，失焦自动暂停。提供触屏备用摇杆和点击投料；PC优先。

```bash
npm run dev
# http://localhost:3000
npm test
npm run check
```

Node 20+ 用于测试；Python3 提供开发静态服务器；无JS依赖、无需构建。`dist/`是直接维护的源码，不是可删除的构建产物。

## 当前规则

- 物质资源，不是原子资源。水枪用水1份装填改装；燃烧模块试验消耗氢气2份和氧气1份，并需炉内点火。
- 配平反应式：2H₂ + O₂ → 2H₂O。产水记入独立收集瓶，不回流可用背包；图鉴可查看。
- 水枪只提高攻速，单发伤害不变；氢燃烧枪命中附带淡蓝色灼烧持续伤害。
- 同系增强，异系替换明确确认并清零旧系等级；两系原型上限Lv.5，满级不再扣材料。
- 材料按背包与炉内总量判断；足够时制作按钮点亮，点击自动扣料（先扣炉内，不足从背包补齐）。拖拽可选；余料立即退回，材料不足/取消替换不扣资源。下一波前自动退回炉内全部材料。
- 首波结束回收掉落并显示教学补给：标准库存至少水1/氢气2/氧气1，确保可选枪；测试加量模式保底水4/氢气6/氧气3。
- 可重复改装后进入第二波；两波后胜利结算，死亡可重开。隐藏高级配方只是未来入口，未实现。

## 科学表述边界

氧气是氧化剂，不是燃料，空气默认含氧。水枪装填不称化学反应；燃烧试验显示反应物、点火条件及产水记录。份数、模块改装、不限弹药、加攻速与持续灼烧是游戏抽象，不是现实实验用量、实际武器制作方法或完整化学仿真。

## 逐关难度与Boss躲招（本轮新增）

普通怪、分裂子体与Boss统一按关卡强化：每提高一关，生命乘1.35、伤害乘1.20，效果在生成时写入实例，界面显示当前倍率。当前仍为两关原型。

反应釜基础生命800，在第二关为1080；接触和技能伤害也受关卡倍率影响。保留阶段召唤，并加入两种专属技能：

- 高压冲击：先预警1.2秒，再向外扩散；绿色角度缺口安全，可走位穿过。过载阶段发射两道错开的冲击环。
- 地面锁定：橙色区域预警1.1秒，随后爆发。预警期间不会造成伤害，移动离开可躲避。
- 生命低于30%过载，出招更频繁、危险区更多。暂停/能力选择期间危险区计时冻结，Boss死亡立即清除技能。

本轮只考验移动与识别招式，普通枪、水枪、氢燃烧枪都能造成正常伤害。用户已提出下一步加入属性相克/减弱；这里只记录该方向，未提前实现或决定具体克制表。难度数值需要实际试玩继续调整。

## 枪型射程与射击表现

普通枪保持短曳光弹，射程600。水枪是带水流高光、波纹和水花的水柱，Lv.1射程260，每级+55，Lv.5为480；子弹到达射程后消失。氢燃烧枪用淡蓝白色翻卷火舌，近距宽扇形即时命中多个可见目标并附加灼烧；Lv.1射程160、总夹角约52°，每级射程+15、夹角略增，Lv.5射程220。距离为游戏单位，以角色为射程原点，不是现实测量。

火焰的可见外轮廓被限制在实际伤害扇形/圆形射程内，火舌也裁剪在该范围中；水枪的射程和攻速随枪等级提升。角色能力继续独立叠加，不因换枪丢失。当前装备面板显示实际射程。

火焰视觉追加：密集流动焰团、多层翻卷火舌、亮芯与发光；点燃目标有火苗、灼烧标记/时长条和合并的“灼烧-N”数字。灼烧仍为Lv.1每秒12点、持续2.5秒，升级每级DPS+5；离开扇形后仍持续到状态结束。

## 新增四枪：射击、特效与配方

当前共六把化学枪，开局均可免费选Lv.1（按1–6）。新增如下：

| 枪型 | 配方材料（份） | 战斗特点 |
| --- | --- | --- |
| 酸液枪 | 盐酸 HCl(aq) ×1 | 绿色酸液弹；命中叠最多3层腐蚀，3秒内增强后续直接命中；升级提高每层效果/射程 |
| 二氧化碳气压枪 | CO₂ ×1 | 短程宽扇形气流，推开多个目标；Boss只受20%击退，目标不能被推出场地 |
| 盐水电弧枪 | NaCl ×1 + H₂O ×1 | 枪械供电，盐水作导电介质；电弧从近处首目标连锁到附近不同目标，伤害逐跳×0.8 |
| 铁弹枪 | Fe ×2 | 远射程、低射速、高伤害、有限贯穿；同一弹不会重复打同一目标 |

Lv.1参数：酸液射程340/间隔0.55s，气压190/0.70s，电弧250/0.65s（跳跃距离110、3目标），铁弹640/0.85s（2目标贯穿）。所有新枪随枪等级提高射程，并提高各自特性。保留同系增强、异系确认清零、Lv.5上限和角色能力独立保留。

物资共7种：水、氢气、氧气、盐酸、二氧化碳、氯化钠、铁。标准总掉率仍18%（测试75%），随机池扩展为全部材料。首波补给保证所持枪至少有一次升级材料；测试加量模式额外备齐多种配方。

新增配方均明确标记为溶液装填、压缩/磁轨装配或溶解与装配，不伪造反应方程式。HCl(aq)说明盐酸溶质，NaCl为离子化合物组成比，Fe为金属单质；腐蚀增伤/击退/电弧/贯穿属于游戏规则。本轮没有加入物质相克、灭火或材质专属弱点。
