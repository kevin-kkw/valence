# VALENCE · 链式反应（短闭环原型）

两波各60秒，第二波需击败失控反应釜Boss（未击败会继续战斗）：普通枪战斗收集水/氢气/氧气物质卡，钻石用于角色能力三选一；波间可直接制作或拖拽投料，按公开配方改装水枪或氢燃烧枪，进入第二波并结算。WASD/方向键移动，自动攻击，ESC暂停，失焦自动暂停。提供触屏备用摇杆和点击投料；PC优先。

```bash
npm run dev
# http://localhost:3000
npm test
npm run check
```

Node 20+ 用于测试；Python3 提供开发静态服务器；无JS依赖、无需构建。`dist/`是直接维护的源码，不是可删除的构建产物。

## 当前规则

- 物质资源，不是原子资源。水枪用水1份装填改装；燃烧模块试验消耗氢气2份和氧气1份，并需炉内点火。
- 配平反应式：2H₂ + O₂ → 2H₂O。产水记入独立收集瓶，不回流可用背包；图鉴可查看。
- 水枪只提高攻速，单发伤害不变；氢燃烧枪命中附带淡蓝色灼烧持续伤害。
- 同系增强，异系替换明确确认并清零旧系等级；两系原型上限Lv.5，满级不再扣材料。
- 材料按背包与炉内总量判断；足够时制作按钮点亮，点击自动扣料（先扣炉内，不足从背包补齐）。拖拽可选；余料立即退回，材料不足/取消替换不扣资源。下一波前自动退回炉内全部材料。
- 首波结束回收掉落并显示教学补给：标准库存至少水1/氢气2/氧气1，确保可选枪；测试加量模式保底水4/氢气6/氧气3。
- 可重复改装后进入第二波；两波后胜利结算，死亡可重开。隐藏高级配方只是未来入口，未实现。

## 科学表述边界

氧气是氧化剂，不是燃料，空气默认含氧。水枪装填不称化学反应；燃烧试验显示反应物、点火条件及产水记录。份数、模块改装、不限弹药、加攻速与持续灼烧是游戏抽象，不是现实实验用量、实际武器制作方法或完整化学仿真。

## 结构与验证

- catalog.mjs：物质、配方、原子组成、Lv.5上限。
- model.mjs：库存/炉内事务、枪型、反应条件、战斗、掉落/保底、波次和结算。
- render.mjs / view.mjs：Canvas绘制与镜头。
- app.mjs / index.html / style.css：操作、实验室、确认、图鉴与界面。
- tests：模型/镜头与DOM冒烟检查，记录见 docs/verification.md。

真实浏览器渲染与原生拖拽/触屏尚未验证：此环境缺少Sites所需cua_repl.js，未绕过其限制。DOM mock不能证明像素布局正确。网站发布成功与玩法验证是不同证据。

## 钻石成长与五种样本怪物

钻石每次击杀必掉，数值按怪物类型配置；物质卡独立按概率掉落。标准18%，主菜单可切换测试加量75%，该选择跨重开保留，本局中不能切换。两种掉落外观分别为钻石和物质瓶。

钻石达到经验门槛时暂停，随机三选一：最大生命、全枪型基础攻速、直接伤害、防御、移速、拾取范围、回血、暴击。换枪保留角色属性；重开才重置。波末回收触发的连续升级完成后返回实验室。

| 怪物 | 行为 | 钻石 |
| --- | --- | --- |
| 酸雾团 | 近距离酸雾脉冲 | 2 |
| 活泼金属小怪 | 快速移动、短暂冲刺，脆皮 | 1 |
| 晶体甲壳兽 | 慢速厚血，半血外壳裂开 | 5 |
| 胶体集群 | 击败分成2个小胶体，小胶体不再分裂 | 3；小胶体各1 |
| 失控反应釜 | 第二波25秒出现，三阶段释放不同样本 | 16 |

这些是虚构拟人化样本；怪物行为与名称不代表现实化学反应，物质卡是回收实验物资。暂不额外添加未经核查的化学克制体系。
