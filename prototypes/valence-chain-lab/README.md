# VALENCE · 链式反应（短闭环原型）

两波各60秒：普通枪战斗收集水/氢气/氧气物质卡，波间拖拽或点击投料，按公开配方改装水枪或氢燃烧枪，进入第二波并结算。WASD/方向键移动，自动攻击，ESC暂停，失焦自动暂停。提供触屏备用摇杆和点击投料；PC优先。

```bash
npm run dev
# http://localhost:3000
npm test
npm run check
```

Node 20+ 用于测试；Python3 提供开发静态服务器；无JS依赖、无需构建。`dist/`是直接维护的源码，不是可删除的构建产物。

## 当前规则

- 物质资源，不是原子资源。水枪用水1份装填改装；燃烧模块试验消耗氢气2份和氧气1份，并需炉内点火。
- 配平反应式：2H₂ + O₂ → 2H₂O。产水记入独立收集瓶，不回流可用背包；图鉴可查看。
- 水枪只提高攻速，单发伤害不变；氢燃烧枪命中附带淡蓝色灼烧持续伤害。
- 同系增强，异系替换明确确认并清零旧系等级；两系原型上限Lv.5，满级不再扣材料。
- 余料立即退回，材料不足不扣资源，下一波前自动退回炉内全部材料。
- 首波结束回收掉落并显示教学补给，库存保底水4/氢气6/氧气3，避免试玩路径被随机性堵住。
- 可重复改装后进入第二波；两波后胜利结算，死亡可重开。隐藏高级配方只是未来入口，未实现。

## 科学表述边界

氧气是氧化剂，不是燃料，空气默认含氧。水枪装填不称化学反应；燃烧试验显示反应物、点火条件及产水记录。份数、模块改装、不限弹药、加攻速与持续灼烧是游戏抽象，不是现实实验用量、实际武器制作方法或完整化学仿真。

## 结构与验证

- catalog.mjs：物质、配方、原子组成、Lv.5上限。
- model.mjs：库存/炉内事务、枪型、反应条件、战斗、掉落/保底、波次和结算。
- render.mjs / view.mjs：Canvas绘制与镜头。
- app.mjs / index.html / style.css：操作、实验室、确认、图鉴与界面。
- tests：模型/镜头与DOM冒烟检查，记录见 docs/verification.md。

真实浏览器渲染与原生拖拽/触屏尚未验证：此环境缺少Sites所需cua_repl.js，未绕过其限制。DOM mock不能证明像素布局正确。网站发布成功与玩法验证是不同证据。
