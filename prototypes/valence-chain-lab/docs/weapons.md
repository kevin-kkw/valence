# 枪械与装备 · 当前V4.11

普通枪开局，双枪同时生效，各自索敌、独立配件/枪口。所有化学枪Lv1、+0的单次直接基础伤害统一18，角色能力、枪械物质Lv和进阶会改变最终数值。

详细伤害、射速、射程、Lv1/Lv10 DPS与+3/+6形态统一维护在[枪械数值总表](weapon-balance-discussion.md)，不在本页复制第二份数值。

| 枪型 | 每次制作或Lv升级材料 | 主要机制 |
|---|---|---|
| 水枪 | 水1 | 连续水柱，攻速最快 |
| 氢燃烧枪 | 氢气2、氧气1，点火 | 近程扇面、灼烧；反应生成水2份 |
| 酸液枪 | 盐酸1 | 溅射、腐蚀增伤，不穿透 |
| 二氧化碳气压枪 | 二氧化碳1 | 扇面击退 |
| 盐水电弧枪 | 氯化钠1、水1 | 初始连锁3个目标 |
| 铁弹枪 | 铁2 | 初始穿透2个目标 |

枪械物质Lv1至Lv10，与同名枪进阶+0至+10独立。每阶直接伤害与主枪灼烧+8%，+3第二形态、+6最终形态，+7至+10继续数值成长。

## 配件

每枪2槽；允许装不适配配件，但不生效，不通过另一配件改变适配条件。掉落优先匹配持枪需求，关间选择安装位置。

| 适配枪 | 配件 | 效果 |
|---|---|---|
| 氢燃烧枪 | 冷凝水包 | 收集燃烧产水，满后侧后方喷水，边喷边补。 |
| 氢燃烧枪 | 余热护环 | 喷火积热，在脚下留下持续燃烧5秒的驻场火环。 |
| 水枪 | 电源模块 | 水流命中后触发闪电链，最多跳跃3个目标。 |
| 水枪 | 制冷模块 | 积蓄后射出冰弹，飞行命中才造成伤害并减速。 |
| 酸液枪 | 泡沫反应包 | 酸液反应积气，投出持续减速泡沫区。 |
| 酸液枪 | 铁粒反应包 | 分流酸液制氢，蓄满后追加短促燃烧。 |
| 二氧化碳气压枪 | 集气包 | 积存主枪气体，周期性环形击退。 |
| 二氧化碳气压枪 | 制冷膨胀模块 | 主喷流周期性扩散冷雾，减速一片敌人。 |
| 盐水电弧枪 | 电容模块 | 积存主枪电能，周期性强化连锁放电。 |
| 盐水电弧枪 | 电磁护环 | 充电后展开护环，偏转附近金属弹。 |
| 铁弹枪 | 磁轨模块 | 电磁加速主枪铁弹，提升弹速和贯穿。 |
| 铁弹枪 | 碎片回收盒 | 回收攻击过程的铁屑，蓄满后释放近身碎片。 |

## 通用枪口

每枪1槽，适用于全部六枪，无负面效果。

| 枪口 | 效果 |
|---|---|
| 聚束枪口 | 射程+35%，直接伤害+10%。 |
| 扩散枪口 | 扩大攻击覆盖；电弧跳距+40%，目标数+1。 |
| 连发枪口 | 攻击间隔缩短25%，保持完整单发伤害。 |
| 分叉枪口 | 双方向发射，每路完整伤害。 |

关末自动收取地上枪/配件/枪口，但仍需在关间完成替换/安装决策。钻石与物质必须亲自拾取，角色强化与枪械升级用途分开。更多规则见[现行规则](current-rules.md)。
