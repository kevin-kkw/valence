# 角色能力（本地V4.4）

战斗中钻石经验累计待选能力，关末集中随机三选一，完成后才生效；换枪保留，重开重置。当前共有九种能力。

| 能力 | 初始值 | 每次升级 | 上限 |
|---|---|---|---|
| 更强体魄 | 生命上限100 | 上限+20，同时当前生命仅恢复20 | 无独立上限 |
| 精准打击 | 基础伤害18 | +3，配件伤害同比例成长 | 无独立上限 |
| 快速装填 | 攻速倍率1 | +0.12，配件按各自蓄力机制响应 | 主枪无独立上限，配件有各自倍率上限 |
| 防护涂层 | 减伤0% | +5个百分点 | 60% |
| 轻盈步伐 | 移速225 | +15 | 无独立上限 |
| 收集力场 | 拾取范围125 | +25 | 无独立上限 |
| 自我修复 | 0生命/秒 | +0.5生命/秒 | 无独立上限 |
| 弱点洞察 | 暴击0% | +8个百分点，暴击2倍直接伤害 | 80% |
| 灵敏反应 | 闪避0% | +5个百分点 | 40% |

闪避范围：普通怪和精英的接触、弹体、地面技能；Boss普通接触也可以闪避，但Boss弹幕、冲击环、地爆、光束、最终Boss突进都属于技能，不进行闪避随机判定。召唤出的普通怪按自己的攻击类型处理。

成功闪避免除本次伤害，产生浅蓝小字“闪避”，不触发受伤事件，并沿用0.8秒通用受击保护，防止贴身每帧重复判定。Boss技能仍遵守通用受击保护。闪避失败后正常计算防御减伤。零闪避率、Boss技能、受击保护期间不消耗闪避随机数。达到40%后移出候选；升级卡显示前后百分比，装备面板显示当前闪避率。

用户已明确授权V4.3部署，本能力与十分钟关卡时长一起发布。后续版本仍须单独获得部署授权。

V4.4将能力选择统一移到关间，详见intermission.md；当前仅本地，V4.3部署授权不自动延续。
