# 角色属性与能力 · 当前V4.11

右侧装备／属性／背包／配方四页签中，属性页集中显示当前/最大生命、已获得等级与经验、待选次数，以及九项能力当前值、基础值和升级增量。单枪最终数值在装备页；切页不暂停战斗。左右键循环，Home/End首尾跳转。进入实验室默认背包，下一关默认装备。

钻石只有实际拾取才提供经验，未捡关末清除。经验门槛8起，每级+5；显示等级即时推进，能力在关间选择后生效，待选次数不预加属性。能力换枪保留，重开恢复基础值。

| 能力 | 初始值 | 每次升级 | 上限 |
|---|---|---|---|
| 更强体魄 | 生命上限100 | 上限+20，同时当前生命仅恢复20 | 无独立上限 |
| 精准打击 | 基础伤害18 | +3，配件伤害同比例成长 | 无独立上限 |
| 快速装填 | 攻速倍率1 | +0.12，配件按各自蓄力机制响应 | 主枪无独立上限，配件有各自倍率上限 |
| 防护涂层 | 减伤0% | +5个百分点 | 60% |
| 轻盈步伐 | 移速225 | +15 | 无独立上限 |
| 收集力场 | 拾取范围125 | +25 | 无独立上限 |
| 自我修复 | 0生命/秒 | +0.5生命/秒 | 无独立上限 |
| 弱点洞察 | 暴击0% | +8个百分点，暴击2倍直接伤害 | 80% |
| 灵敏反应 | 闪避0% | +5个百分点 | 40% |

闪避适用于普通/精英接触、弹体与技能，以及Boss普通接触；不适用于Boss技能，包括最终Boss突进。成功免本次伤害，显示“闪避”并沿用0.8秒受击保护。防御与闪避达到上限后不再进入候选。暴击造成2倍直接伤害，持续伤害不按同一口径暴击。

角色攻击加成会影响配件伤害；攻速对配件按其蓄力规则生效，有各自上限。参见[关间流程](intermission.md)与[现行规则](current-rules.md)。
