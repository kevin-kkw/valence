# 配方路线演示（概念草案）

入口：`/recipe-demo.html`。用户要求先做 demo 理解“制备物质 → 装配枪械”的两层结构。

初始库存 Fe×2、HCl×4、C×1、O₂×1。可选择直接用 Fe×2 装配铁弹枪，也可用 Fe×1 和 HCl×2 制取 H₂×1，获得 FeCl₂×1 副产物，再装配氢燃烧枪；制氢后剩余 Fe 不够直接装铁弹枪。装配本身是游戏操作，不伪装成化学反应。气压枪示例需先点燃 C 与 O₂ 制备 CO₂。数量是游戏抽象份数，溶液按溶质组分记账。

独立演示库存，不接入主游戏；新增 C 与 FeCl₂ 仅用于本页。测试枪装配成本是便于展示分支的草案，不是正式平衡调整。既有六枪战斗和七种掉落物保持原有规则。

验证：模型测试检查元素守恒、副产物留存、材料不足不扣料、条件与重置；DOM/canvas mock 检查按钮流程及特效调用。未做真实浏览器视觉验收。
