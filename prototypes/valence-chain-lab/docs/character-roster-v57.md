# V5.7 人物与形象设计

本地候选，未部署。用户确认不同人物/职位，三名青少年形象，前两名男性、朵朵女性。实现统一采用17岁青年实验项目成员设定，避免资深成年人的职业经历。

标准/快速装备测试开始前必须选人。人物卡显示立绘、名字、职业、擅长与虚构简介；没有默认选中，确认后普通枪开局。取消返回基地；重开再选。一次完整对局各幕沿用同一角色，角色随幕间存档保存。旧存档无身份字段时兼容使用大奇。

## 大奇

- 性别：男
- 职位：材料工程师
- 擅长：铁与金属材料 · 磁轨装备
- 简介：青年实验项目的材料组成员。大奇喜欢拆开旧设备，把还能使用的零件收进工具箱。他报名参加新型装备测试，想验证自己的材料笔记，也想弄明白 VELA 提供的那些陌生零件来自哪里。

## 强尼

- 性别：男
- 职位：燃烧技师
- 擅长：氢氧燃烧 · 灼烧与余热
- 简介：青年实验项目的热能组成员。强尼总把护目镜挂在额头上，喜欢研究反应装置启动时细微的变化。听说这次能测试全新的便携装备，他第一个交了申请表，还认真记下了 VELA 的每一句测试提示。

## 朵朵

- 性别：女
- 职位：溶液研究员
- 擅长：水与电解质 · 导电联动
- 简介：青年实验项目的溶液组成员。朵朵的采样包上贴满手写标签，里面总留着一个空瓶。她把装备测试当作一次难得的现场观察：收集样本、核对记录，再把那些看似普通的小现象，拼成自己的发现。
