# 血瓶 · 当前本地 V5.8.4

普通小怪独立1.5%概率掉落，普通子体也可掉，精英/Boss不额外掉血瓶。不替代钻石、物质或枪掉落，物质测试加量开关不改变血瓶掉率。

- 每瓶最多恢复10HP，缺血不足10只恢复实际差额，显示实际回血数字。
- 缺血时与钻石共用磁吸和拾取流程：进入人物“拾取范围”后以相同速度靠近，触碰后恢复生命。初始范围125；朵朵及“收集力场”等加成同样生效。不弹窗、不入关间队列、不加经验。
- 满血不消耗、不磁吸，原地保留；再次受伤后恢复磁吸。关内不设消失倒计时。
- 未捡关末清除，不回血、不带到下一关、不延长战斗。
- 暂停、关间、失败、通关时不拾取，不能复活。

参数位于catalog.mjs的HEALTH_PICKUP：chance=.015、healing=10；不再单独配置拾取距离。医疗、恢复能力和放弃装备回血仍保留，关间无自动回血。[现行规则](current-rules.md)。
