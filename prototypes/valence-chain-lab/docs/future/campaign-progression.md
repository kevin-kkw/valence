# 后续设计：实验、外勤任务与隐藏终局

状态：主线结构与遗物取得规则已获用户确认；尚未实现。当前已上线游戏仍为V4.11十关原型，现行机制见[现行规则](../current-rules.md)。本文不是施工计划，未确定的剧情与机制列于末尾。

## 设计目标

首先好玩，化学知识通过装备、配方及现象自然进入玩法。玩家起初仅认为自己在测试新型装备，随后以正常工作为由执行任务。采用类似《安德的游戏》的信息遮蔽：玩家并不知道完整目的，故事通过任务与线索逐步展开。不要在第二幕直接宣布真相或明确把任务称为骗局。

核爆只是多种终极构筑中的一种，属于少数对局得到关键机会后可追求的路线，不是每局必得或唯一终局通行条件。高级配方、反应连锁、终极构筑组成后续玩法方向；具体配方、条件与数值未定。路线通过线索和可观察现象发现，不提前直接告知终极名称与完整达成条件。已有发现可跨地图、跨游戏局记录。

## 已确认的主线结构

1. 第一幕是“测试新型装备”，不是仅测试防护装备。以现有十关实验为起点，成功后进入外勤阶段。
2. 前三张外勤地图开放选择顺序：化学工业城、异质矿区、封闭生态基地。每次任务是独立的一场十关挑战。
3. 每张地图有一种特别遗物；前三张图分别提供三件不同的主线遗物。玩家必须成功完成对应任务并带回基地，才永久获得。
4. 主线遗物在该地图首次成功通关时必得，用户已明确确认。失败时不能把这次取得的遗物计入长期档案。集齐至少需要三次成功外勤，未成功的尝试不推进遗物收集。
5. 三件不同遗物集齐后，获得一把钥匙，第四张地图选项才出现，此前不能进入。不是集齐后在前三张地图随便开一扇门替代终局。
6. 第四张地图暂采用微观物质世界的方向。进入后用钥匙打开门，迎战最后的Boss并揭露故事秘密。第四张自身特别遗物的用途尚未定。
7. 四张地图都存在门。前三张探索时打不开，构成共同谜面；这些门与第四张门之间的具体关系尚未定。

第一幕之后的成功进度路径：三项可选任务，各完成并带回独有遗物 → 三件组合出钥匙 → 隐藏的第四任务出现 → 开门、终局Boss与秘密。玩家可跨多局逐步推进，不要求一口气完成所有地图。

## 地图与任务方向

| 地图 | 当前讨论的正常任务外壳 | 地图特色方向 |
|---|---|---|
| 化学工业城 | 恢复停机设备、检修生产设施 | 酸雾管道、结晶车间、金属加工与废液处理 |
| 异质矿区 | 调查矿源、采样、处理开采障碍 | 晶体洞穴、金属矿层、地下气室 |
| 封闭生态基地 | 排查循环故障、恢复环境平衡 | 水循环、气体交换、矿物沉积、生物胶体 |
| 微观物质世界 | 材料内部修复的任务外壳 | 晶格、离子通道、聚合物等视觉与机制方向 |

上表是世界和任务方向，不代表具体关卡、敌人、Boss或剧情台词已获最终确认。前三地图顺序自由，故事不能依赖固定先后，需通过局部事件与共享线索拼合。

- 每张任务的首领组合；遗物成功结算必得，但如何在关卡内呈现尚未定。
- 第四张地图的特别遗物、钥匙消耗/重开规则、终局失败后的重试入口。
