# VALENCE：配件驱动的化学乐趣

## 本轮用户确认的方向

先有好玩的游戏，再在玩的过程中认识化学。不要让玩家先理解元素、配平、制备流程，才能获得好玩的武器。上一版配方路线演示信息过密、流程太绕，保留作历史探索，不作为新的主体验。

新的核心循环：打怪获得材料或配件 → 合成配件包 → 装到枪上 → 立即改变攻击方式。用户提出普通枪加火焰包变喷火枪，氢氧可以合成水包；进一步提出初始氢氧包无限，喷火过程中生成水，装上空水包便持续收集，积蓄到一定程度后让枪同时向其他方向喷水。用户明确喜欢此方向，并要求记录全部思路和制作 demo。

“主攻击产生物质，配件把产物变成另一种能力”是当前值得验证的核心。副产物应成为看得见的奖励，战斗变化应先于知识说明。化学知识通过外观、连贯因果与可选知识卡表达。无限初始包属于用户提出的游戏假设，不作为现实化学结论。

## 配件创意记录

以下均已讨论；除第一项外，本轮只记录，尚未实现，也不是最终配方或平衡。

| 主枪 / 配件 | 战斗乐趣 | 化学依据与游戏处理 |
| --- | --- | --- |
| 氢氧喷火枪 + 冷凝水包 | 前方喷火时积水，蓄满后朝侧后方喷水，补足背后防御 | 2H₂ + O₂ → 2H₂O（点燃），水蒸气冷凝；收集、加压与自动瞄准由配件完成 |
| 水枪 + 电源配件 | 先打湿怪群，再用电弧连锁攻击 | 含有溶解离子的水可以导电，纯水导电能力很弱；电能来自电源，不是水凭空发电 |
| 水枪 + 制冷配件 | 积攒冰弹，击退逼近的敌人 | 水凝固，是物态变化；能量消耗与冰弹发射属于配件设定 |
| 碳燃烧枪 + 集气包 | 开火积气，蓄满后环形推开包围的怪物 | 碳充分燃烧：C + O₂ → CO₂（点燃）；气体由机械结构收集加压，击退不是 CO₂ 自带能力 |
| 酸液枪 + 碳酸氢钠反应包 | 分流少量酸液积气，换来一次气压冲刺 | 以盐酸为例：HCl + NaHCO₃ → NaCl + H₂O + CO₂↑；冲刺来自加压机构，碳酸氢钠配件的有限储量后续确定 |
| 盐水枪 + 蒸发结晶盒 | 持续攻击时积累盐晶，蓄满射出一圈晶体碎片 | 水蒸发、盐结晶，属于分离与物理变化；碎片攻击和积累速度为游戏表现 |

还记录了多配件连锁的设想：喷火生成水 → 冷凝水包收集 → 水流打湿敌人 → 电源配件触发连锁电击。第一阶段先验证一个主枪配一个配件是否有趣，再决定多槽组合。储水用于侧后方攻击或保留作紧急护身喷射，是未来可讨论的取舍，尚未实现。

先前“同系增强、异系替换清零”适用于旧单枪版本。多配件规则与旧升级机制如何衔接尚未确定，不能直接当成已批准的新规则。也不能把本轮 demo 的免费装卸当成正式掉落/制作系统。

## 本轮可玩 demo

入口 `/pack-demo.html`，主菜单也有入口。独立试验场，现有六枪主游戏、旧配方演示与土豆 demo 保留。

实现者为快速验证手感选择：

- 60 秒生存，开局无限氢氧喷火枪，默认装空的冷凝水包；无需材料、配平或制造步骤。
- 保留原版开枪规则：射程内有敌人才按原射速自动开火，每次锁定最近目标；不增加鼠标瞄准或手动开停火。直接使用主游戏 gunStats 的 Lv.1 火枪参数（射程160、半夹角0.45、射击间隔0.42秒、直接伤害18、灼烧12/秒持续2.5秒），特效按原射击时刻生成。WASD / 方向键移动，触屏摇杆备用。
- 实际喷火累计约五秒蓄满水；只有火焰正在喷射且装配水包时积蓄。无目标时原枪不会发起射击，已有火焰特效结束后不再补水。
- 水包蓄满才启动自动喷水，优先选当前主射向以外超过 60°的侧后方目标；没有目标便朝后喷。喷水持续消耗储水，主枪开火时同时补水，停火便不补水。耗水速度高于补水速度，因此持续开火也会逐渐见底；空包立即停止喷水，必须重新蓄满才再次启动。当前默认补水速度每秒容量的 20%，喷水消耗每秒约 55.6%，满包停火可喷约 1.8 秒，持续开火可喷约 2.8 秒。此规则来自用户本轮补充，具体速率为实现默认。
- 水流用世界空间弹道，玩家转身不会让已射出的水跟着甩动；水流有命中、穿透与轻微推力；火焰保留直接伤害与离开后的灼烧。
- Q 或按钮装卸水包，拆卸清空储水，便于对比。靠近或远离怪物自然触发原版自动开火与停火，用来体验边喷边补与停火耗水。空格 / Esc 暂停；窗口失焦与切到后台自动暂停。重开清零并装上空包。
- 背包水位、环形进度、蓄满提示、命中水花和统计帮助理解配件作用。知识说明折叠，非开玩前置门槛。

这是经用户授权的可玩概念验证，以上具体数值和自动触发是本轮默认，待试玩评价。未来仍需验证自动瞄准是否有足够走位乐趣、蓄水等待是否合理，以及是否要加入配件拾取与成长。

## 验证范围

模型检查：蓄水、自动释放、无配件不收集、停止射击不收集、暂停冻结、侧后方选敌、水弹轨迹/命中、灼烧、边界和重置。UI mock 检查开局、特效调用、蓄满、暂停恢复、装卸与重开。全项目 `npm test`、`npm run check` 与 `git diff --check`。

当前环境缺少 Sites 所需的正式浏览器工具，未进行真实浏览器视觉或触屏验收；不把 DOM/canvas mock 当成实际画面验证。

## 试玩纠正：原版开枪逻辑必须保留

用户反馈“配件大约是这个意思，但不要改之前的开枪逻辑”。已移除本 demo 曾加入的鼠标瞄准、手动开停火、无目标持续喷火与独立修改的火枪数值，恢复原版自动射程判定、最近目标锁定、按射速攻击和灼烧。配件是叠加能力，不得以增加配件为由改写基础枪的操作与行为。主游戏 model.mjs 未修改。

## 原版主游戏整合（最新）

用户强调要在原版设计上继续，而不是独立简化试验场。冷凝水包现已直接整合至 `/` 主游戏，保留原 UI、六枪开局选择、钻石能力升级、怪物、波间实验室和 Boss。原有主枪攻击代码保留，新增 Condenser 只在主枪攻击处理之后运行；直接伤害、射程、射速、目标选择与灼烧不变。

试玩方式：从原菜单选择氢燃烧枪开始，默认携带免费空冷凝水包。原装备侧栏显示水位与状态，可在战斗、暂停和实验室中装卸水包以作对比。其他枪保留原玩法，不会产水。无限初始包、冷凝收集、蓄满自动向侧后方喷水、开火补水/喷水耗水/空包需重新蓄满沿用前述规则。水弹走原 hit 管线，击杀正常掉钻石/物资；Boss 推力降为20%。暂停与升级会冻结水包状态，跨波清空场上水流、保留储水，重开恢复空包。

新增原游戏模型回归：无目标不蓄水、满包启动、边喷边补、停火耗空与重新蓄满、主枪伤害与射击节奏不变、配件水流击杀掉落、暂停及重置。主 UI mock 增加水包栏、喷射与装卸检查。仍未完成真实浏览器视觉验收。

旧 `/pack-demo.html` 仅保留作历史演示，不再作为主试玩入口或后续开发基础。正式配件掉落、制造、槽位成长及其他五种配件尚未实现。
