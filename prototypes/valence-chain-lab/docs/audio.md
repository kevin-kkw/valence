# V4.8 本地：轻科幻街机音效

用户选择轻科幻街机风。使用浏览器Web Audio合成，零外部音频文件、零下载依赖，可嵌入独立HTML。默认开启，只有点击开始/装备试验或开启声音时才创建并解锁音频；右上角♫可立即静音并停止当前声音。没有背景音乐。

| 事件 | 声音 |
|---|---|
| 普通枪 | 短促电子弹声 |
| 水枪 | 滤波水流与短促滑音 |
| 氢燃烧枪 | 低频喷焰与噪声 |
| 酸液枪 | 两段下落的气泡音 |
| 气压枪 | 排气声与低音冲击 |
| 电弧枪 | 电击脉冲与高频噪声 |
| 铁弹枪 | 低频弹击与金属高频瞬态 |
| 钻石/物质/装备拾取 | 分别为短音、双音、装配三音 |
| 血瓶/医疗 | 上行双音 |
| 受击 | 低沉下降冲击 |
| 能力/制作/进化 | 上行提示，+3/+6进化专用三音 |
| 精英/Boss/转形 | 双脉冲预警、低音登场、上升转形 |
| Boss技能 | 新地面/冲击环/光束预警，最终Boss突进预备也提示 |
| 胜利/失败 | 上升终止式/下降终止式 |

两把枪按各自当帧实际射击槽触发音效，不随当前查看枪改变。密集拾取合并，射击按枪槽限频；普通音最多18个振荡/噪声源，总计最多24个，预留警告等重要音容量。主输出压缩器限制密集叠加。暂停、整备和结算停止旧战斗声音，不积压静音期间的声音；浏览器不支持/拒绝音频时游戏继续。

验证：模型/事件/生命周期测试；真实Chromium点击解锁AudioContext、静音按钮；离线渲染全部音效并检查非静音、有限值、未削波，生成试听WAV。主观音色和音量仍需玩家本机试听反馈。

复测：`node tests/browser-audio.mjs <CDP地址> <游戏URL> [试听WAV路径]`。仅本地未部署。
