# 关间整备 · 当前V4.11

战斗中不因能力升级、满槽换枪或装备安装而弹出选择。已拾取钻石即时推进显示等级/经验条，属性在关间分配后生效。空槽化学枪自动装备，同名枪即时进阶；其他需选择的拾取先入待整备队列。

关末先自动收取地上枪、配件、枪口；未捡的钻石、物质、血瓶清除，不加经验、不入背包、不回血。没有免费材料补给，不再因地上装备显示LOOT等待。HUNT保底枪未掉落、特殊敌人未击败的加时要求保留。

顺序：能力三选一 → 满槽换枪 → 逐箱配件/枪口 → 实验室。重复枪可按前次换枪后的持枪情况自动进阶；配件候选按处理时的持枪组合优先匹配。选择之间不运行战斗帧，时间冻结，不刷怪、不持续回血。

安装弹窗取消返回原箱，不消耗奖励。放弃一箱配件/枪口最多恢复50HP，不能重复领取。必须处理完队列才能下一关。实验室默认背包，下一关默认装备。

医疗每次用关卡编号+2份物质换最多5HP；不自动回血。最终Boss死亡立即通关，不为待选拖延；死亡不会被待选能力复活，重开清空队列。
