# V4.4：关间集中选择

战斗中不再因角色能力升级、满槽异系枪、配件或枪口选择而暂停。

- 钻石经验仍即时收集，达到阈值仅累计待选能力，不提前升级或修改属性。HUD显示待选数量。
- 空槽化学枪仍自动装备，同名枪仍立即进阶，这两种操作无需选择。
- 满槽异系枪和装备箱拾取后入待整备队列，战斗照常，尚未安装的新装备不产生效果。
- 仍须走到装备掉落旁拾取；不磁吸、不在关末自动收走。原有LOOT/HUNT/BOSS延长规则保留。

关末顺序：连续完成能力三选一 → 处理满槽换枪 → 配件/枪口逐箱选择与安装 → 实验室。枪械队列中若某枪因前一次替换已变成同名，则自动进阶并继续。配件候选按处理时的持枪组合优先匹配。

整备期间不运行战斗、不推进时间、不触发刷怪或持续回血；不会在连续选择之间插入一帧战斗。能力体魄回血与放弃战利品最多50回血继续在选择时生效。安装弹窗取消保留当前箱，不消费奖励。队列未处理完不能开始下一关。

最终Boss死亡仍立即通关，不为待选项拖延结算；死亡不会通过待升级自动复活，重开清空全部队列。角色等级及属性只有选择完成后才增长。

验证：36个模型测试文件、UI流程、语法检查通过；真实Chromium跑通战斗中积累3次能力/3件装备而不中断，关末连续升级→换枪→安装取消→两个连续装备箱→实验室→下一关，战斗时间全程冻结，无控制台异常。独立队列审查无重要问题。

用户已明确要求部署V4.4，当前版本获准发布；后续版本仍须单独授权。
